# DogWars — отдельный бот обратной связи

Бот принимает идеи, сообщения об ошибках и вопросы. Обращения сохраняются в Supabase и приходят в отдельную Telegram-группу. Администратор отвечает на сообщение бота — пользователь получает ответ в личном чате с ботом. Есть статусы «В работу» / «Закрыть», команда `/my` и добровольная поддержка через Telegram Stars.

Это самостоятельный проект. Он не меняет игровой бот, питомцев, территорию, косточки и сайт DogWars. Можно использовать тот же проект Supabase: схема `dogwars_feedback` и функция `dogwars-feedback` имеют отдельные имена. VPS не нужен; используются Supabase Edge Functions.

## Установка по шагам

Понадобятся существующий **отдельный** бот из BotFather, Telegram-группа, Python 3.12 и Node.js с `npx`. Откройте терминал в папке **этого проекта**, где находятся `supabase`, `scripts` и этот README. Команды ниже подходят для PowerShell и Git Bash на Windows; пути заключены в кавычки, слеши `/` работают в обоих терминалах.

### 1. Подготовьте секреты на компьютере

```sh
py -3.12 "./scripts/configure_feedback_bot.py" --init
```

Введите токен отдельного бота из BotFather. Ввод скрыт — это нормально. Проверьте показанное имя бота и подтвердите, что это не игровой бот. Скрипт создаст файл `.env.feedback` с токеном и новым случайным `FEEDBACK_WEBHOOK_SECRET`. Его не нужно придумывать или вводить в чат.

Файл содержит секреты: не отправляйте его в GitHub, группу или чат. Он уже исключён через `.gitignore`. Для Stars отдельный платёжный провайдер и банковские реквизиты в настройках бота не требуются.

### 2. Установите один SQL-файл

Откройте Supabase → проект `fywsqxijebneqkxusgro` → **SQL Editor → New query**. Скопируйте **весь** файл:

`supabase/migrations/202611090001_feedback.sql`

Нажмите **Run**. Существующие миграции игры заново выполнять не нужно. Результат `pg_advisory_xact_lock` — нормальная часть установки. Этот SQL можно повторить: имеющиеся обращения не удаляются.

### 3. Загрузите секреты и отдельную функцию

В терминале из корня проекта:

```sh
npx supabase login
npx supabase secrets set --env-file ".env.feedback" --remote=fywsqxijebneqkxusgro
npx supabase functions deploy dogwars-feedback --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Подтвердите развёртывание **dogwars-feedback**. Функцию **paws-api** менять не нужно. Если ваша старая версия CLI не знает `--remote`, используйте `npx supabase@latest` вместо `npx supabase`.

`--no-verify-jwt` нужен для Telegram: вместо Supabase JWT функция проверяет отдельный секрет в заголовке webhook. Анонимное чтение таблиц и выполнение RPC запрещены.

Проверка функции в браузере:

https://fywsqxijebneqkxusgro.supabase.co/functions/v1/dogwars-feedback/health

Должен появиться JSON с `service: "dogwars-feedback"`, `configured: true`. Пока `group_configured` и `admins_configured` будут `false` — зададим их ниже. Если видите `NOT_FOUND`, сначала завершите deploy и проверьте название функции.

### 4. Подключите Telegram

```sh
py -3.12 "./scripts/configure_feedback_bot.py"
```

Скрипт установит webhook **отдельного** бота, включит обработку сообщений и платежей и настроит меню команд. Токен не выводится. Существующий webhook другого назначения автоматически не заменяется: это защищает от случайного использования игрового токена.

### 5. Укажите администратора и группу

1. Откройте бота в Telegram, нажмите **Start** и отправьте `/id`. Пока настройка не закончена, работает именно `/id`.
2. Скопируйте свой положительный Telegram ID из ответа.
3. Добавьте бота в группу обратной связи. Разрешите ему отправлять сообщения. Делать его администратором группы необязательно.
4. В группе отправьте `/id@имя_вашего_бота`. Скопируйте отрицательный ID чата, обычно он начинается с `-100`.
5. Откройте локальный файл `.env.feedback` в редакторе. Внизу заполните две строки, сохранив токен и секрет без изменений:

```dotenv
FEEDBACK_ADMIN_IDS=ВАШ_ПОЛОЖИТЕЛЬНЫЙ_ID
FEEDBACK_ADMIN_CHAT_ID=ОТРИЦАТЕЛЬНЫЙ_ID_ГРУППЫ
```

Для нескольких администраторов перечислите ID через запятую без пробелов. Ссылки `@username` здесь не подходят. Члены группы, чьи ID не перечислены, не смогут отвечать пользователям или менять статус через бота.

Повторно загрузите секреты и проверьте настройку:

```sh
npx supabase secrets set --env-file ".env.feedback" --remote=fywsqxijebneqkxusgro
py -3.12 "./scripts/configure_feedback_bot.py"
```

На странице `/health` все три признака готовности должны стать `true`. Если после смены секретов они ещё не обновились, повторите deploy `dogwars-feedback` из шага 3. Отключать Privacy Mode у бота не требуется: команды и ответы на его сообщения Telegram доставляет и с включённым режимом приватности.

### 6. Проверьте обращения

- В личном чате с ботом отправьте `/start` → «Предложить идею» → текст.
- В группе появится обращение с номером и кнопками статуса.
- В группе **ответьте на это исходное сообщение бота** текстом. Ответ придёт пользователю в личный чат с ботом. Поддерживаются текстовые ответы администратора до 3000 символов.
- Нажмите «В работу» или «Закрыть»: пользователь получит уведомление.
- Отправьте боту `/my`: увидите свои последние обращения. Для администраторов в группе есть `/inbox` — последние 20 незакрытых обращений.
- Проверьте отправку фотографии с описанием. Она копируется в группу с тем же номером обращения. Для нескольких фотографий отправляйте каждую отдельным сообщением: альбом автоматически не объединяется.

Прямой текст без выбранной категории принимается как вопрос. Обращения: до 3000 символов, не чаще одного за 10 секунд. Команда `/cancel` возвращает меню.

Если в группе несколько ботов, адресуйте команды явно: `/inbox@имя_вашего_бота`, `/refund@имя_вашего_бота НОМЕР_СЧЁТА`.

### 7. Проверьте Stars

Кнопка **«❤️ Поддержать разработчика»** или `/support` предлагает ввести целое число от 1 до 10 000 ⭐. Затем бот присылает счёт Telegram Stars. Игровые косточки и бонусы за поддержку не начисляются.

**Оплата настоящая**, не тестовая. Для проверки можно оформить счёт и отменить его без оплаты. Завершайте оплату только если хотите действительно перечислить Stars. Бот благодарит после подтверждённого платежа Telegram, а не после нажатия кнопки. У каждого счёта есть уникальный номер; повторная доставка события не создаёт повторную запись об оплате.

Запросы об оплате и возврате: `/paysupport`. Администраторам в группе приходит номер оплаченного счёта. Для полного возврата администратор отправляет в группе:

```text
/refund НОМЕР_СЧЁТА_ИЗ_УВЕДОМЛЕНИЯ
```

Здесь номер счёта — UUID, не номер обращения. Возврат выполняется через Telegram `refundStarPayment`. Команда сохраняет запрос в очередь; окончательный статус виден в Supabase в `dogwars_feedback.donations`: `paid` / `refunded`. При временной ошибке запрос остаётся в очереди. Проверка суммы, валюты XTR и плательщика выполняется на сервере. Для оплаты выставленный счёт действителен час; после этого откройте поддержку заново.

Полученные Stars, условия вывода и доступность вывода проверяйте в Telegram/BotFather для этого бота. Курс к рублю бот не устанавливает.

## Работа и данные

В Supabase Table Editor выберите схему `dogwars_feedback`:

| Таблица | Назначение |
| --- | --- |
| `tickets` | Обращения, авторы и статусы |
| `sessions` | Выбранная категория или ожидание суммы Stars |
| `donations` | Счета и подтверждения платежей |
| `updates` | Защита от повторной обработки событий Telegram |
| `outbox` | Очередь доставки сообщений и возвратов |

Таблицы закрыты для `anon` и `authenticated`, функция использует автоматически выданный Supabase `service_role`. В приватный чат ответы идут только владельцу обращения. Бот не имеет доступа к игровому аккаунту и не связывает его с обращением автоматически.

Очередь отправляется при каждом новом событии бота. Если Telegram временно недоступен, сообщение сохраняется, повторная попытка возможна через 15–300 секунд при следующих событиях. `/inbox` также запускает отправку очереди. **Без новых событий автоматического таймера нет**: для обязательной фоновой доставки настройте расписание POST-запросов к `.../dogwars-feedback/retry` с заголовком `X-Telegram-Bot-Api-Secret-Token` из `FEEDBACK_WEBHOOK_SECRET`. Не включайте секрет в URL или открытые задания. Статус очереди — колонка `delivered`, временные ошибки — `last_error`.

При редком сетевом обрыве после принятия сообщения Telegram повторная доставка сообщения возможна. Создание обращения и учёт платежей защищены уникальными ключами в базе.

Обращения, платежи и очередь сами не удаляются. Удаление данных по запросу обрабатывает владелец: сначала проверьте автора через его чат с ботом, затем удалите относящиеся к нему обращения, сообщения в группе и персональные данные в базе. Сохраняйте необходимые платёжные записи для возвратов и учёта; бот не обещает автоматического удаления платёжных операций.

Бесплатные квоты, остановка неактивного проекта и ограничения Supabase зависят от вашего тарифа. Старый игровой токен, игровой webhook_secret и `paws-api` для этой установки не нужны.

## Проверки исходного кода

Без доступа к Telegram:

```sh
deno check supabase/functions/dogwars-feedback/index.ts
deno test supabase/functions/dogwars-feedback/handler_test.ts
python -m unittest discover -s tests -p "test_*.py"
```

`tests/database_checks.sql` проверяет реальную SQL-логику на временной локальной PostgreSQL после установки миграции. Запускать его в рабочей базе не нужно.
