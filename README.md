# Encrypted DogWars conversation handoff

Download this branch as ZIP, unpack it and open OPEN_BACKUP.html locally in a current browser. Enter the password supplied separately in the originating chat. Save the decrypted ZIP and use 01_START_HERE.md for the new conversation.

Only encrypted content is hosted here. No password, project credentials, plaintext transcript, or source-code changes are included. The decrypted package explicitly distinguishes reconstructed history from available messages; it is not a full platform conversation export.
