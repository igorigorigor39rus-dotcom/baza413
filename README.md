# Лапы на карте — Telegram-бот + Mini App

Теперь приложение работает **через Telegram**, без Expo Go, Node.js и отдельного мобильного приложения. Python-бот показывает кнопку «Открыть карту», а Mini App внутри Telegram отвечает за карту, профиль питомца и GPS.

Обычный чат бота не умеет непрерывно записывать GPS, поэтому нужен именно Mini App. Для настоящей прогулки необходимы HTTPS, разрешение на геолокацию и открытый экран приложения. Поведение Telegram WebView нужно проверить на конкретных iOS/Android-устройствах.

Старый мобильный прототип сохранён в [коммите 700aa4a](https://github.com/igorigorigor39rus-dotcom/baza413/tree/700aa4a7dc89657b943671d0e502224a08dc790e). Текущая версия его больше не использует.

## Что реализовано

- Вход через Telegram с проверкой подписи, без отдельного пароля.
- Один профиль питомца на владельца: кличка, возраст, описание, фото и цвет.
- Карта OpenStreetMap через Leaflet, без API-ключа для первого теста.
- GPS-маршрут, замыкание в пределах 5 м, закраска территории.
- В новых клиентах используется Telegram LocationManager, при его отсутствии — Geolocation API браузера. Точность и разрешения зависят от телефона.
- Общая серверная база: пользователи одного бота видят участки друг друга.
- Перезахват пересечения: оставшаяся часть, отверстия и островки сохраняются.
- Фото-маркер открывает карточку владельца. Поля человека из Telegram не публикуются.
- Демо без токена и GPS: вымышленный сосед Бублик и пошаговый маршрут.

## 1. Сначала проверьте на компьютере, без Telegram

Установите **Python 3.12** с [python.org](https://www.python.org/downloads/). На Windows отметьте добавление Python в PATH. Откройте терминал в распакованной папке с README и requirements.txt.

Windows, обычная командная строка cmd:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --no-access-log
```

macOS / Linux:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --no-access-log
```

Копируйте `.env.example` **только один раз**, не перезаписывайте существующий `.env`. В примере включён `DEMO_MODE=true`.

Откройте на этом же компьютере **http://127.0.0.1:8000**. Терминал оставьте открытым. Остановка сервера — `Ctrl+C`.

1. Создайте профиль питомца и выберите цвет.
2. Нажмите **«Пройти демомаршрут»**.
3. Четыре раза нажмите **«Следующая точка»**.
4. Нажмите **«Захватить территорию»**: часть участка Бублика перейдёт вам.
5. Нажмите на фото-маркер и проверьте карточку владельца.
6. Перезагрузите страницу: профиль и территория сохранятся.

Демо использует один тестовый аккаунт для всех посетителей этого сервера: **не публикуйте его в интернете**. Тестовая база и фото отделены от настоящих: `data/demo.sqlite3`, `data/demo-photos/`. Настоящий режим использует `data/app.sqlite3`, `data/photos/`.

## 2. Подключите настоящего Telegram-бота

Понадобятся токен от BotFather и **публичный HTTPS-адрес** HTTP-сервера. Без них подключение к настоящему Telegram ещё не готово. Одна общая Wi-Fi-сеть не заменяет HTTPS.

### Создайте бота

1. Откройте официальный [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте название и username, заканчивающийся на `bot`.
3. Полученный токен сохраните только в локальный `.env`. Не присылайте его в чат и не коммитьте в GitHub.

### Получите HTTPS для короткого теста

Можно использовать Cloudflare Tunnel: установите `cloudflared` по [официальной инструкции](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/).

**Сначала остановите демосервер** сочетанием `Ctrl+C`, чтобы не открыть тестовый аккаунт публично. В отдельном терминале запустите:

```sh
cloudflared tunnel --url http://127.0.0.1:8000
```

Скопируйте выданный адрес вида `https://случайное-имя.trycloudflare.com`. Пока сервер остановлен, tunnel может сообщать о недоступном origin — это ожидаемо. Tunnel требует доступности Cloudflare из вашей сети; он не запускался при разработке. После перезапуска его адрес может измениться.

### Измените .env

```dotenv
DEMO_MODE=false
TELEGRAM_BOT_TOKEN=ваш_настоящий_токен
APP_URL=https://ваш-публичный-адрес
```

Подставьте свои значения. Сервер и бот должны использовать **один и тот же токен**. Не вставляйте его в браузерный JavaScript: сервер применяет токен для проверки подписи Telegram.

### Запустите сервер и бота

Заново запустите HTTP-сервер той же командой из раздела 1: `.env` перечитывается при запуске. Во втором терминале из папки проекта запустите бота:

Windows:

```bat
.venv\Scripts\python.exe -m backend.bot
```

macOS / Linux:

```sh
.venv/bin/python -m backend.bot
```

Для теста с tunnel одновременно работают **три процесса**: сервер, бот и cloudflared. Компьютер должен оставаться включённым. Общая Wi-Fi-сеть с телефоном не обязательна.

1. Откройте личный чат бота и отправьте `/start`.
2. Нажмите **«🐾 Открыть карту»**. Бот также устанавливает кнопку меню «Карта».
3. Создайте профиль: при переключении с демо настоящая база начинается отдельно.
4. Выйдите на улицу, нажмите «Начать захват», разрешите точную геолокацию.
5. Обойдите простой контур, вернитесь к старту и нажмите «Захватить территорию».

При открытии настоящей версии просто в браузере вход будет отклонён: нет подписанного Telegram `initData`. Открывайте через кнопку бота.

Для проверки общей карты второй человек открывает **того же бота**, создаёт свой профиль и обходит пересекающийся контур. Входы разные, сервер и база общие.

## GPS и правила захвата

- Замыкание — до 5 м по измеренным координатам. Физическую точность 5 м GPS не гарантирует.
- Точность принимаемой точки — до 15 м, последняя точка при захвате — не старше 15 секунд.
- Уход в фон, сворачивание Telegram или блокировка экрана прерывает запись. Поддерживаемый устройством Wake Lock помогает удерживать экран, но доступен не во всех WebView.
- Разрыв точного GPS больше 45 секунд отменяет прогулку. Неподвижный шум фильтруется, но каждые 5 секунд сохраняется временная отметка.
- От 4 до 5000 точек; до 2 часов; радиус до 10 км от старта; площадь от 25 м² до 10 км². Широты за пределами ±85° и переход через линию смены дат пока не поддерживаются.
- Самопересечения, слишком быстрые скачки координат и некорректное время отклоняются. Это базовая проверка, а не полноценная защита от подделки GPS.
- Незавершённый маршрут хранится в памяти страницы и не восстанавливается после закрытия.

## Разбор кода с опорой на Python

| Файл | Назначение |
| --- | --- |
| `backend/bot.py` | Команды `/start`, `/help`, `/privacy`, кнопка Mini App, получение сообщений через polling. |
| `backend/app.py` | FastAPI: профиль, фото, прогулка, захват, общая карта; выдача HTML/JS/CSS. |
| `backend/auth.py` | HMAC-подпись Telegram, срок входа и ID владельца. |
| `backend/geometry.py` | Чистые функции проверки маршрута, площади, расстояния и разности полигонов. |
| `backend/database.py` | SQLite, таблицы и преобразование записей в публичные данные. |
| `backend/config.py` | Настройки в `dataclass`, чтение `.env`, пути баз и фото. |
| `backend/demo.py` | Фиксированный маршрут только для демонстрации. |
| `web/index.html` | Разметка экрана, кнопок и форм. |
| `web/style.css` | Оформление и адаптация под телефон. |
| `web/app.js` | Состояние экрана, Leaflet, кнопки, GPS и запросы к Python API. |
| `web/tracking.mjs` | Независимые функции фильтрации GPS на телефоне. |
| `web/location.mjs` | Получение координат через Telegram LocationManager или браузерный GPS. |
| `tests/test_app.py` | Вход, геометрия, фото, сохранение, одновременный перезахват. |
| `tests/test_bot.py` | Бот с подменённым Bot API, без отправки настоящих сообщений. |

JavaScript `async/await` похож на Python: ждёт ответов без блокировки экрана. `fetch()` обращается к FastAPI. Объект `state` хранит текущий профиль и прогулку, `render()` обновляет кнопки. Leaflet визуализирует карту, а решение о владении принимает сервер.

Захват вычисляет `старый участок − новый контур` для пересекающихся территорий, затем добавляет участок нового владельца. `BEGIN IMMEDIATE` в SQLite не позволяет конкурентным запросам потерять изменения друг друга. Собственные прежние участки тоже обрезаются, чтобы не было двойного владения.

GeoJSON использует `[долгота, широта]`, Leaflet обычно принимает `[широта, долгота]`. Порядок координат важен.

## Проверки разработчика

В активированном окружении либо с полным путём к Python из `.venv`:

```sh
python -m unittest discover -s tests -v
python -m pip check
```

Сейчас **21 тест Python**. Необязательная проверка браузерного фильтра при установленном Node: `node tests/tracking.test.mjs`. Для работы приложения Node не нужен.

Браузерный сценарий: установите `requirements-dev.txt`, выполните `python -m playwright install chromium`, запустите демосервер и затем `python tests/browser_smoke.py`. Скрипт меняет тестовый профиль: используйте отдельную базу через `DATA_DIR`. Можно задать путь установленного Chromium в `BROWSER_PATH`.

Браузерный тест проверяет профиль, демопрогулку, перезахват, карточку и сохранение после reload. Telegram SDK и тайлы в нём подменены: он не подтверждает работу настоящего Telegram, интернет-подложки карты и GPS телефона.

## Данные и ограничения

- `.env` и `data/` не коммитятся. Для согласованной резервной копии остановите сервер и скопируйте весь `data/` с SQLite и фото.
- В настоящем режиме обязательно `DEMO_MODE=false`: демонстрация специально отключает вход.
- На сервере сохраняются Telegram ID, профиль, фото и контуры территорий. Полный маршрут приходит для проверки, но в базе не сохраняется. Контур участка остаётся публичным. Фото перекодируется без исходного EXIF. Не включайте домашний адрес или другие личные данные в описание.
- Подпись входа действует час. При истечении откройте Mini App заново через бота.
- Тайлы OpenStreetMap загружаются из интернета. Соблюдайте [политику OSM](https://operations.osmfoundation.org/policies/tiles/); для массового сервиса нужен подходящий поставщик тайлов. Google, Яндекс и 2ГИС пока не подключены.
- Показывается до 200 участков текущей области, при превышении предлагается приблизить карту. Для большой нагрузки нужны оптимизация SQLite, геометрии и ограничения запросов.
- Фоновая запись, полноценная защита от GPS-подмены, модерация и удаление аккаунта через интерфейс пока не реализованы. Они нужны перед широким публичным запуском.
- Для постоянной работы нужны HTTPS-домен, постоянный диск, резервное копирование, ограничения запросов на reverse proxy и автоперезапуск двух Python-процессов. Временный tunnel — для теста.
- Не запускайте два polling-процесса с одним токеном. Если раньше был настроен webhook, переключите его осознанно; программа сама его не удаляет.
- В облачной среде для бота требуется сетевой доступ к `api.telegram.org`. Локальное демо Telegram API не использует.

Цвет на карте — игровая механика, которая не даёт права заходить на частные или закрытые участки.
