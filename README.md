# Защищённый бэкап

Скачайте ZIP этой ветки, распакуйте и откройте `OPEN_BACKUP.html` в Chrome или Edge. Введите пароль, полученный в личном чате. Браузер сохранит внутренний ZIP с файлами бэкапа. Интернет для расшифровки не нужен.

Этот репозиторий содержит только зашифрованный контейнер. Пароль и открытый текст переписки здесь не хранятся. Бэкап охватывает доступный контекст, а не полную платформенную выгрузку всех сообщений.
