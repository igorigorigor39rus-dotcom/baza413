# Лапы на карте · baza413

Первая версия приложения для владельцев собак на **iOS и Android**. Общий код написан на React Native с Expo и TypeScript. Комментарии и эта инструкция — на русском.

## Что уже есть

- Локальный профиль питомца: кличка, возраст, описание, фотография и цвет территории.
- Карта: Google Maps на Android, Apple Maps на iOS через `react-native-maps`.
- «Начать захват»: запрос разрешения и запись GPS-маршрута при открытом приложении.
- «Захватить»: проверка замкнутости в пределах 5 м и закраска внутренней площади.
- Перезахват: новая территория вырезает пересечение из прежних участков. Отверстия и отдельные островки сохраняются.
- Фото владельца на территории; нажатие открывает карточку питомца.
- Сохранение профиля и реальных территорий на телефоне между запусками.
- Демопрогулка без GPS с вымышленной территорией Бублика. Демо не меняет реальные сохранения.

**Это локальный прототип.** Аккаунтов с паролем, сервера и обмена данными между телефонами пока нет. Настоящие чужие территории появятся после подключения сервера; сейчас их перезахват можно проверить в демо.

## Запуск на телефоне

Нужны Node.js 24.3+ (использован 24.22.1), npm и совместимый с Expo SDK 58 клиент Expo Go на телефоне.

```sh
cd /workspace/baza413
npm ci
npm start
```

На своём компьютере замените путь на каталог скачанного репозитория. Телефон и компьютер должны быть в одной сети. Откройте проект по QR-коду в Expo Go: на Android из приложения, на iPhone через камеру. Если установленный Expo Go не поддерживает SDK 58, потребуется совместимая версия клиента или собственная development-сборка.

Облачный сервер не находится в локальной сети телефона: QR с его внутренним адресом может быть недоступен. Самый простой первый запуск — скачать репозиторий на свой компьютер и выполнить команды выше. Облачная проверка сборки не подтверждает запуск на телефоне.

### Проверка без прогулки

1. Создайте профиль. Фото необязательно.
2. Нажмите «Попробовать без GPS». Появится оранжевый участок Бублика.
3. Нажмите «Начать демопрогулку», затем четыре раза «Следующая точка».
4. Нажмите «Захватить». Новый контур закрасится вашим цветом, а Бублику останется непересечённая часть.
5. Нажмите на фото владельца. Выйдите из демо: пробных территорий на реальной карте не будет.

### Проверка настоящей прогулки

1. Выйдите из демо, выйдите на открытое место и нажмите «Начать захват».
2. Разрешите точное местоположение. Дождитесь GPS; первая принятая точка станет стартом.
3. Обойдите участок без самопересечений и вернитесь к старту в пределах 5 м.
4. Нажмите «Захватить». При открытом контуре приложение объяснит причину отказа и оставит запись активной.
5. Перезапустите приложение и проверьте сохранение территории и фото.

Запись работает **только при открытом приложении**. Экран во время записи не гаснет. Уход в фон или блокировка экрана отменяет реальную прогулку: пропущенный GPS-путь нельзя честно восстановить прямой линией. Незавершённый маршрут после закрытия приложения не сохраняется.

GPS не гарантирует точность 5 м. Точки с заявленной погрешностью больше 15 м отбрасываются; для захвата нужна принятая точка не старше 15 секунд. Порог замыкания 5 м применяется к измеренным координатам. На настоящих устройствах понадобится подобрать правила обработки GPS и проверить поведение в плотной застройке.

## Проверки разработчика

```sh
npm run check       # TypeScript и 12 тестов геометрии/GPS
npm run export      # JavaScript-бандлы iOS и Android, результат в dist/
```

`export` не создаёт устанавливаемые APK/IPA и не проверяет нативный GPS или отображение карты на телефоне. Для этого нужны устройство либо эмулятор/симулятор. iOS-симулятор требует macOS и Xcode, Android-эмулятор — Android Studio.

## Как устроен код, если вы знакомы с Python

| Файл | За что отвечает |
| --- | --- |
| `App.tsx` | Главный экран, состояния прогулки, подписка на GPS, карта и действия кнопок. React-компонент — функция, возвращающая описание интерфейса. |
| `src/components/PetEditor.tsx` | Форма профиля, выбор фото и копирование фотографии в постоянное хранилище приложения. |
| `src/types.ts` | Описания структур `Pet`, `Position`, `Territory` — похожи на типизированные `dataclass` в Python. |
| `src/domain/territory.js` | Чистые функции проверки маршрута и перезахвата. Не знают про экран, телефон или хранилище. |
| `src/domain/territory.d.ts` | Типы параметров и результатов для функций JavaScript, чтобы TypeScript проверял их использование. |
| `src/storage.ts` | Чтение и запись данных на устройстве через AsyncStorage. Версия формата нужна для будущих обновлений. |
| `src/demo.ts` | Вымышленный сосед и заранее заданный маршрут для демонстрации. |
| `tests/territory.test.js` | Проверки замыкания, самопересечений, площади, перезахвата, отверстий, островков и фильтра GPS. |
| `app.config.js` | Название приложения, идентификаторы платформ, разрешения и подключение нативных модулей. |

В React `useState` хранит состояние экрана и вызывает перерисовку при изменениях. `useRef` хранит объекты, например подписку GPS, без перерисовки. `useEffect` подключает обработчики и отключает их при закрытии экрана. `async/await` работает похоже на Python: ждёт завершения операции без блокировки интерфейса.

### Алгоритм захвата

`validateRoute` проверяет число точек, расстояние до старта, отсутствие самопересечений и минимальную площадь 25 м². Остаточный зазор до 5 м закрывается коротким отрезком. Turf вычисляет площадь и геометрическую разность. Для каждого существующего участка вычисляется `старый участок − новый контур`, затем добавляется участок нового владельца. Это работает и для своих прежних территорий, чтобы не было двойного владения.

Карта принимает `{latitude, longitude}`, а GeoJSON/Turf — `[longitude, latitude]`. Порядок координат важен. Результат сохраняется как Polygon или MultiPolygon с возможными отверстиями.

## Собственные Android/iOS-сборки

Expo Go подходит для первого знакомства. Перед собственной сборкой Android включите **Maps SDK for Android** в Google Cloud и задайте `GOOGLE_MAPS_ANDROID_API_KEY` в окружении сборки. `app.config.js` передаст его плагину карты. Ключ попадает в мобильное приложение: ограничьте его Android package `com.baza413.paws` и SHA-1 сертификата подписи. Без него карта в собственной Android-сборке не готова. Не коммитьте локальный `.env`.

iOS использует Apple Maps и не требует ключа Google Maps. Для установки собственной iOS-сборки на устройство и публикации нужны инструменты/аккаунт Apple. Android/iOS package names в конфигурации — начальные значения, их следует согласовать перед публикацией. Яндекс и 2ГИС пока не подключены.

## Следующий этап

Серверная регистрация владельца, загрузка фотографий, общая база территорий и атомарная проверка перезахватов на сервере. Телефону нельзя доверять окончательное решение о владении: понадобятся проверки GPS-подмены и конфликтов одновременных прогулок. Затем — фоновая запись с отдельными разрешениями, полевые испытания GPS и подготовка к магазинам приложений.

Маршруты и фото сейчас хранятся локально без серверного резервного копирования. Удаление приложения может удалить их. Цвет на карте — игровая механика, он не даёт права доступа к частным или закрытым участкам.
