# Обновление v0.3 — Бюро собачьих дел

Сайт GitHub Pages публикуется из prototype /docs. Подготовлены: детективная тема, Hue 0–359°, насыщенность и прозрачность, сплошная/камуфляжная/полосатая/сетчатая заливка, общий чат и косточки.

## Обновить уже работающий Supabase

1. В Supabase → SQL Editor → New query вставьте **только новый файл** `supabase/migrations/202611060001_dossier.sql` целиком и нажмите Run. Базовая миграция 202611050001 уже установлена; повторно её не запускайте. Существующие профили и территории сохраняются.
2. На своём компьютере скачайте свежий ZIP релиза и распакуйте в новую папку. Откройте терминал в ней. Выполните:

   ```sh
   npx supabase login
   npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
   ```

   На старом CLI вместо `--remote` используется `--project-ref`. Секреты TELEGRAM_BOT_TOKEN / WEBHOOK_SECRET / APP_URL сохраняются в Supabase, заново вводить их и переустанавливать webhook не требуется.
3. Проверьте `https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health`: ожидается `{"ok":true}`. Затем `/api/config`: ожидается `features` с dossier/chat/wallet = true. Эти два адреса не содержат секретов.
4. Закройте Mini App и откройте заново через бота. В досье доступны новые параметры заливки, в оперативной связи — общий чат, вверху — баланс и ставка косточек.

Без авторизации Supabase из облачной среды применить SQL и загрузить функцию нельзя. Если обновлён только сайт, совместимость с прежним API сохраняется: GPS-захват и старые профили работают, новые стили отключены до обновления сервера.

## Яндекс.Карты

Используется официальный JavaScript API 2.1 через Leaflet-адаптер leaflet-plugins 3.4.0 (лицензия сохранена). Ключ не подставляется автоматически.

1. Получите ключ «JavaScript API и HTTP Геокодер» в кабинете разработчика Яндекса; проверьте действующие условия/тарифы API для вашего приложения.
2. Ограничьте браузерный ключ доменом `igorigorigor39rus-dotcom.github.io`.
3. В `web/config.mjs` задайте `YANDEX_MAPS_API_KEY`. Это публичный браузерный ключ, **не токен Telegram и не service_role**.
4. Выполните `python scripts/build_pages.py`, отправьте web/ и docs/ на GitHub и дождитесь Pages. Выберите «Яндекс» над картой.

Без ключа переключатель объясняет причину и оставляет OpenStreetMap. Подложка Яндекса, её точность совмещения и загрузка в Telegram должны проверяться с настоящим ключом. Проверки разработки не обращались к платному API и не подтверждают работу реального ключа. Авторские подписи поставщика карты не отключаются.

## Экономика

1 косточка за 1 м² за 1 час. Награды за старые территории начинаются с момента установки новой миграции, а не с их исторического создания. Уже заработанные косточки не сгорают при перезахвате.

Сервер вычисляет интеграл площади по времени. Перед каждым изменением территории старый доход фиксируется в одной транзакции. Дробная часть хранится без округления до целого; интерфейс показывает целое количество. Доход начисляется офлайн, без cron и без постоянно открытого приложения. Баланс обновляется при входе, после захвата и каждые 30 секунд на открытом экране.

## Чат

Общий канал всех участников этого бота, последние 100 сообщений. Обновление каждые 10 секунд, отправка от имени питомца с проверенным сервером владельцем, ограничение — одно сообщение в 3 секунды. Текст выводится безопасно, HTML не выполняется. Досье участника, его имя и текущая фотография публичны на карте; в сообщениях показываются кличка и время. Чат открывается поверх карты и сам по себе не прерывает GPS. Уход Telegram в фон по-прежнему отменяет запись.

Модерация и удаление сообщений через интерфейс в этот релиз не входят. Для большой публичной аудитории нужны модерация и дополнительные ограничения нагрузки.

## Проверки разработчика

- `deno task --config supabase/functions/deno.json test`: 15 тестов Edge Function.
- После обеих миграций **только в одноразовом Docker PostGIS**: `python tests/dossier_checks.py -v` — 5 проверок начислений, конкуренции, потери территории, чата, прав и повторной миграции.
- `tests/pages_smoke.py`: реальный Chromium с подставленными Telegram SDK и тайлами; Hue, камуфляж, профиль, фото, захват, безопасный чат, счётчик, перезагрузка.

Python backend/ — предыдущий справочный сервер; новые функции выпуска работают на Supabase.
