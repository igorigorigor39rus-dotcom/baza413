# Обновление DogWars до v.1.0

Демо удалено; добавлены породы и штаб с десятью уровнями. Территории, косточки, досье, чат, покупки Stars и репарации сохраняются. Доход остаётся 1 🦴 за 10 м² в сутки. Улучшения штаба не увеличивают доход.

## 1. Скачать файлы

Скачайте [ZIP v.1.0](https://github.com/igorigorigor39rus-dotcom/baza413/archive/refs/tags/v.1.0.zip), распакуйте в новую папку. Откройте терминал в папке, где находятся `README.md`, `scripts` и `supabase`.

## 2. Обновить базу

В [Supabase → SQL Editor](https://supabase.com/dashboard/project/fywsqxijebneqkxusgro/sql/new) → **New query** вставьте **весь** файл [202611060009_v10.sql](../supabase/migrations/202611060009_v10.sql) → **Run**.

Это одно накопительное обновление для работающих версий v0.2–v.0.9. Промежуточные миграции не нужны. Для совершенно новой установки сначала выполните `202611050001_paws.sql`, затем v10. Старые миграции после v10 не запускайте.

`pg_advisory_xact_lock` в результате — нормальная блокировка операций. Повторный запуск v10 сохраняет баланс, прогресс штаба и суточные начисления. Для старых досье порода сначала не указана: игрок выбирает её при следующем редактировании. Все начинают с первого уровня штаба.

## 3. Загрузить функцию

В терминале из папки нового архива:

```powershell
npx supabase login
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Подтвердите **Yes**. Откройте [проверку готовности](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health): ожидается `{"ok":true,"version":"1.0.0"}`. В `/api/config` должны быть `features.breeds: true`, `features.headquarters: true`, `features.dailyIncome: true` и `features.geoChat: true`.

Секреты остаются прежними. Webhook и расписание напоминаний, настроенные для v.0.8–v.0.9, перенастраивать не нужно. Для первой установки используйте шаги 3–5 [README](../README.md); для расписания — [инструкцию v.0.8](UPDATE_V0_8.md#5-включить-расписание-напоминаний). Для настройки webhook команда с кавычками работает в PowerShell и Git Bash:

```powershell
py -3.12 "./scripts/configure_supabase_bot.py"
```

Вводите секреты только в своём терминале или Supabase Secrets.

## 4. Проверить приложение

GitHub Pages публикуется из `prototype` / `docs`. Закройте Mini App и откройте через бота заново после завершения публикации. Без подписанного входа Telegram профиль недоступен; `?demo=1` больше не включает демонстрацию.

1. Откройте досье → введите часть названия породы → выберите строку с иконкой. Найти можно и по английскому названию. Для отсутствующей породы выберите собственный ввод.
2. Сохраните досье → нажмите **«Штаб»** рядом с «Оперативной связью».
3. В первом штабе — бетонные стены, старый лежак и миска; шкала показывает **0%**. Питомец дышит, моргает и виляет хвостом. При включённом системном уменьшении движения анимация отключается.
4. При достаточном балансе нажмите **«Улучшить»**, проверьте точную цену в подтверждении. Улучшение меняет комнату и шкалу; максимальный уровень — десятый, **100%**.

| Переход | Цена, 🦴 |
| --- | ---: |
| 1 → 2 | 100 000 |
| 2 → 3 | 200 000 |
| 3 → 4 | 400 000 |
| 4 → 5 | 800 000 |
| 5 → 6 | 1 600 000 |
| 6 → 7 | 3 200 000 |
| 7 → 8 | 6 400 000 |
| 8 → 9 | 12 800 000 |
| 9 → 10 | 25 600 000 |

Всего с первого до десятого уровня — **51 100 000 🦴**. Списывается доступный баланс; незавершённый суточный доход потратить нельзя. Цену и уровень проверяет сервер. Повтор запроса после потери ответа защищён от повторного списания; одновременные улучшения не могут оплатить один уровень дважды.

## Как устроены породы и графика

В локальном справочнике 560 записей пород, разновидностей и метисов. Это широкий открытый каталог, а не обещание единого всемирного реестра: у организаций разные списки признания. Редкие названия могут быть на английском; собственный ввод позволяет указать любое отсутствующее название. [Источники и лицензии](../web/assets/BREEDS_SOURCE.md).

Персонажи нарисованы в одном векторном стиле: общая анимация, 14 типов анатомии и дополнительные варианты окраса/пропорций для распространённых пород. Это стилизованные игровые образы; не для каждой из 560 записей есть отдельный уникальный рисунок. Для своего названия используется общий персонаж.

Десять комнат сгенерированы в одном стиле; исходный лист хранится в `design/hq-levels-concept.png`, облегчённый атлас — в `web/assets/hq/rooms-atlas.webp`. Комната, питомец и свет — отдельные слои. Понятные комментарии в `web/headquarters.mjs`, `web/dog.mjs`, `web/breeds.mjs` и SQL поясняют их назначение.

Обновление GitHub само не применяет SQL и Edge Function в рабочем Supabase. Шаги 2–3 выполняет владелец проекта.
