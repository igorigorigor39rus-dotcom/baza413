# DogWars v.1.1 — единая инструкция обновления

Сайт обновлён через GitHub Pages. Для уже работающего бота достаточно скачать файлы, выполнить один SQL-файл и загрузить функцию. Существующие секреты и webhook остаются прежними. Публикация GitHub не применяет SQL и Edge Function в Supabase автоматически.

Скачайте [архив обновления v.1.1](https://github.com/igorigorigor39rus-dotcom/baza413/releases/download/v.1.1/baza413-v.1.1.zip), распакуйте в новую папку и откройте папку `baza413-v.1.1`, содержащую `README.md` и `supabase`. Компактный архив содержит все рабочие файлы. Оригиналы PNG иллюстраций есть в полном Source code ZIP на [странице релиза](https://github.com/igorigorigor39rus-dotcom/baza413/releases/tag/v.1.1).

## 1. Обновить базу

В [Supabase → SQL Editor](https://supabase.com/dashboard/project/fywsqxijebneqkxusgro/sql/new) → **New query** вставьте **весь** файл [202611080001_v11.sql](../supabase/migrations/202611080001_v11.sql) → **Run**.

Это накопительное обновление для существующих v0.2–v.1.0; промежуточные SQL не нужны. При первой установке сначала выполните `202611050001_paws.sql`, затем v11. Старые миграции после v11 не запускайте. `pg_advisory_xact_lock` — нормальная блокировка операций.

Баланс, земля, досье, уровень штаба, суточные начисления и покупки сохраняются. Повторный запуск v11 их не обнуляет. Уже аннулированный из-за старого правила маршрут не восстанавливается автоматически: отмените его и начните новую трансляцию.

## 2. Загрузить Edge Function

Откройте терминал в папке **этой версии**, содержащей `README.md` и `supabase`:

```powershell
npx supabase login
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Подтвердите **Yes**. Откройте [health](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health): ожидается `{"ok":true,"version":"1.1.0"}`. В `/api/config` должны быть `features.sharedPet`, `features.unlimitedGpsGap` и `features.landscapeHQ` со значением `true`.

Действующие секреты, webhook и расписание с v.1.0 менять не требуется. Для первой установки используйте [README](../README.md), включая настройку webhook и напоминаний.

## 3. Обновить интерфейс

Интерфейс уже публикуется из `prototype` / `docs`. Загружать `docs` вручную и менять Settings → Pages не требуется.

После выполнения SQL и загрузки Edge Function полностью закройте Mini App и откройте снова через бота. Старый HTML из открытого WebView может показывать прежний штаб. В новой версии вверху — объёмный заголовок DogWars, кнопка «Профиль» и фото под ней; штаб открывается на весь экран горизонтально.

## 4. Второй аккаунт

1. Основным аккаунтом откройте **Профиль** под надписью DogWars.
2. В разделе «Второй Telegram-аккаунт» укажите `https://t.me/username` или `@username` второго человека. Нужен публичный username.
3. Нажмите **«Создать приглашение»**, скопируйте полученную ссылку и передайте её второму аккаунту.
4. Вторым аккаунтом откройте ссылку в Telegram, нажмите **Start / Запустить**, затем **«Подтвердить привязку»** в сообщении бота.
5. Откройте карту через бота: оба аккаунта увидят одного питомца и общий баланс.

Ссылка действует 24 часа и только для указанного публичного username, подтверждённого Telegram. В базе хранится хеш токена. Ввод чужой ссылки сам по себе никому не даёт доступ. При создании нового приглашения старое перестаёт действовать.

Второй аккаунт получает прогулки, изменение досье, чат, покупку земли, улучшение штаба и трату общего баланса. Основной аккаунт сохраняет управление привязкой. Допускается один второй аккаунт на питомца; один аккаунт нельзя привязать сразу к двум питомцам. Аккаунт со своим досье автоматически не объединяется с другим: это сохраняет его землю, историю и платежи. Для привязки пока нужен аккаунт без собственного питомца.

Чтобы отозвать доступ, основным аккаунтом откройте профиль и нажмите **«Отключить второй аккаунт»**. Общие данные сохраняются; активная прогулка второго аккаунта отменяется. Приглашение можно отменить отдельно. Автоматические напоминания и уведомления о репарациях по-прежнему направляются основному аккаунту.

Покупки Stars вторым аккаунтом зачисляются общему питомцу. В счёте отдельно фиксируются плательщик и получатель. Уже подтверждённый платёж и его возврат остаются у исходного питомца даже после отключения второго аккаунта; новая оплата по неподтверждённому старому счёту после отключения не принимается.

## 5. Одна трансляция на питомца

Начавшая прогулку трансляция закрепляется за Telegram ID аккаунта и `message_id`. Вторая трансляция с другого аккаунта или другого сообщения не смешивается с текущей. Параллельные попытки старта обрабатываются последовательно в базе.

Статус видят оба аккаунта, отменить прогулку могут оба. **Завершить захват может только аккаунт, начавший трансляцию.** Если гуляет другой аккаунт, кнопка захвата в Mini App заблокирована с пояснением; сервер проверяет это независимо от кнопки.

Telegram не передаёт боту физический идентификатор устройства. Поэтому механизм гарантирует один поток и один аккаунт захвата; два телефона с одним Telegram-аккаунтом, управляющие одним и тем же сообщением трансляции, для бота неразличимы.

## 6. Что изменилось в GPS

Пауза между GPS-точками больше 45 секунд больше не отменяет прогулку — ни при приёме трансляции, ни при финальном захвате. После паузы принятые точки соединяются прямой линией; отсутствующий путь не восстанавливается.

Сохраняются: порядок временных отметок, точность до 20 м, замыкание в пределах 20 м, свежесть последней точки до 15 секунд, проверка средней скорости до 20 км/ч, защита от скачков GPS, максимум 2 часа / 5000 точек / радиус 10 км. Пересечения разрешены; GPS-захват не выплачивает репарации.

## 7. Штаб и рисунки

- Десять новых горизонтальных комнат в стиле подземного штаба: от потрескавшегося бетона и старого лежака до генеральских покоев.
- Весь экран занимает сцена. Запрашивается полноэкранный режим и горизонтальная ориентация; если ОС/WebView не поддерживает поворот, поворачивается сама сцена. При физическом повороте телефона она подстраивается под новый размер.
- 120 отдельных иллюстраций пород без каски, в едином стиле референса; движение — лёгкое дыхание/покачивание. При системном уменьшении движения анимация отключена.
- В справочнике 566 пород, разновидностей и метисов. Разновидности могут делить рисунок, а варианты без отдельной иллюстрации используют ближайший тип внешности. Это не 566 уникальных рисунков.
- Иконки в поиске остаются в прежнем векторном формате. Американская акита, разновидности бельгийской овчарки и папильон выделены отдельно для выбора разных рисунков.
- Нижняя шкала находится поверх комнаты, с 0% слева, 100% справа и текущим процентом. Кнопка улучшения — снизу по центру. Ссылка выбора породы и пояснение об удвоении цены убраны из штаба.
- Цены не изменены: 1→2 — 100 000 🦴, каждый следующий переход ×2. Максимум — уровень 10; всего 51 100 000 🦴. Улучшения не увеличивают доход от территории.

[Локальная галерея 120 пород](../design/breed-gallery-v11.html) открывается через HTTP-сервер проекта; например `python -m http.server 8002`, затем `http://localhost:8002/design/breed-gallery-v11.html`. Это лист просмотра графики вне Mini App, без кошельков, GPS или игровых данных.

Исходники иллюстраций — `design/dogs-v11-*.png` и `design/hq-v11-bunker.png`. Приложение использует сжатые WebP-атласы и загружает только нужный лист. `web/hq-pet.mjs` выбирает рисунок, `web/headquarters.mjs` управляет сценой, `web/accounts.mjs` — настройкой привязки. Комментарии в этих файлах поясняют основные шаги.
