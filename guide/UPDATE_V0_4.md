# ЕДИНАЯ инструкция обновления до v.0.4

Подходит и для работающей v0.2, и для v0.3. Отдельно устанавливать v0.3 не нужно. Профили, фотографии, территории и уже начисленные 🦴 сохраняются.

## 1. Скачать новый релиз

Скачайте ZIP https://github.com/igorigorigor39rus-dotcom/baza413/archive/refs/tags/v.0.4.zip и распакуйте в новую папку. В ней должны быть README.md, supabase/, scripts/, web/.

## 2. Установить ОДИН SQL-файл

Откройте https://supabase.com/dashboard/project/fywsqxijebneqkxusgro → SQL Editor → New query.

Вставьте весь файл **supabase/migrations/202611060002_v04.sql** из нового архива и нажмите Run. Это накопительное обновление: содержит необходимые функции v0.3 и дополнения v.0.4. Повторное применение сохраняет баланс. Базовую миграцию 202611050001 и старую 202611060001 повторно не запускайте.

Если появляется ошибка, остановитесь и пришлите её текст без секретов. SQL выполняется одной транзакцией; не применяйте отдельные куски.

## 3. Обновить функцию Supabase

В Проводнике откройте новую папку проекта, нажмите адресную строку, введите cmd и Enter. Выполните:

```sh
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Если CLI просит вход, выполните `npx supabase login` и повторите загрузку. На старом CLI вместо --remote используется --project-ref.

Токен, APP_URL и WEBHOOK_SECRET остаются прежними в Supabase Secrets. Повторно запускать configure_supabase_bot.py не нужно.

## 4. Убедиться, что обновлён именно сервер

Откройте:

https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health

Ожидается `{"ok":true,"version":"0.4.0"}`.

Затем:

https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/api/config

Проверьте `version: "0.4.0"`, а в `features` — `dossier`, `chat`, `wallet`, `publicWallet`: true. Если их нет, работает старая функция. Если они false, не установлена новая SQL-схема или база недоступна.

## 5. Проверить в Telegram

Полностью закройте Mini App и откройте через кнопку бота. При необходимости обновите страницу/кеш Telegram.

- В досье подвигайте Hue, насыщенность, плотность; выберите узор. Предпросмотр теперь доступен даже до обновления сервера. **Сохранение узоров в общей карте требует шагов 2–3.** На старом сервере сохраняются профиль и цвет, а причина недоступности остальных функций показывается явно.
- Выберите обычную фотографию с камеры. Исходник может быть больше 1 МБ: до 30 МБ/50 Мп. Изображение превращается в JPEG до 1 000 000 байт, перед сохранением сервер снова убирает метаданные. Старые фотографии не удаляются и автоматически не перекодируются.
- Отправьте сообщение через «Оперативная связь». Без обновления сервера кнопка сопровождается объяснением, а не молча теряет сообщение. Общий чат — 100 последних сообщений, обновление каждые 10 секунд, пауза между отправками 3 секунды. При ошибке введённый текст сохраняется.
- Нажмите на питомца другого владельца: появится свежий серверный снимок его баланса 🦴. Просмотр не меняет чужой кошелёк.
- Нажмите «Правила 🦴» возле своего баланса. Формула: 1 м² × 1 час = 1 🦴. Офлайн-начисление продолжается; дробная часть накапливается; заработанное сохраняется после потери участка.

## Карта и оформление

Яндекс, его библиотека, ключ и переключатель удалены. Основная карта — OpenStreetMap. Дополнительная подложка — OpenTopoMap (рельеф), без API-ключа. Для неё сохранены подписи OpenStreetMap/SRTM/OpenTopoMap и лицензия CC-BY-SA. При недоступности нескольких тайлов рельефа приложение вернётся к OSM.

Бесплатные публичные тайлы имеют ограничения нагрузки: см. https://operations.osmfoundation.org/policies/tiles/ и https://opentopomap.org/about . Это не обещание неограниченного коммерческого хостинга.

Фон, диалоги, поля, кнопки и стандартные иконки — графитовые. Цвета фотографий и пользовательских заливок сохраняются. В счётчиках и карточках используется 🦴 вместо длинных подписей.

## Что означает публикация GitHub Release

GitHub Pages автоматически публикует интерфейс из prototype /docs. Он не применяет SQL и не загружает Edge Function в Supabase. В среде разработки нет Supabase Access Token/пароля базы, поэтому шаги 2–3 выполняет владелец аккаунта. Секреты в чат присылать не нужно.

Демо `https://igorigorigor39rus-dotcom.github.io/baza413/?demo=1` доступно без Supabase: сообщения, территории и 🦴 в нём локальны этому браузеру и не попадают в рабочую базу.
