# DogWars — обновление v.0.7.1: выкуп и репарации

Дополнение к v.0.7 с правилом 5. Можно выкупать нейтральную и чужую землю, а свои участки расширять и объединять. Цена — **10 🦴 за 1 м², которого у покупателя ещё нет**.

**При физическом захвате через GPS репарации не выплачиваются.** Это правило одинаково для обычной записи и трансляции геопозиции Telegram.

## 1. Скачать свежий архив

Скачайте [ZIP v.0.7.1](https://github.com/igorigorigor39rus-dotcom/baza413/archive/refs/tags/v.0.7.1.zip), распакуйте в новую папку. Корень проекта — папка с README.md, scripts и supabase. Архив v.0.7 не содержит этого дополнения.

## 2. Выполнить один SQL-файл

Откройте [проект Supabase](https://supabase.com/dashboard/project/fywsqxijebneqkxusgro) → **SQL Editor → New query**.

Вставьте **весь файл** `supabase/migrations/202611060006_v071.sql` из нового архива и нажмите **Run**. Дождитесь успешного завершения. Пустой результат `pg_advisory_xact_lock` нормален: блокировка освобождается при завершении транзакции.

Это накопительное обновление для работающих v0.2–v.0.7. Старые миграции повторно выполнять не нужно, включая уже установленную v.0.7. Для совершенно новой базы сначала выполните `202611050001_paws.sql`, затем новый файл. Профили, территории, балансы и старые чеки сохраняются. При ошибке не запускайте отдельные фрагменты — пришлите текст ошибки без секретов.

## 3. Обновить Edge Function

В Проводнике откройте корень новой папки проекта → адресная строка → `cmd` → Enter. Выполните:

```sh
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Если требуется вход: `npx supabase login`, затем повторите команду. На вопрос о загрузке paws-api в ваш проект отвечайте **Yes**. Старый CLI использует `--project-ref` вместо `--remote`.

Токен бота, APP_URL и WEBHOOK_SECRET остаются прежними. **После работающей v.0.6 или v.0.7 повторно настраивать webhook не надо.** При переходе с более старой версии настройте его по README командой `py -3.12 "./scripts/configure_supabase_bot.py"` с прежними действующим токеном и секретом. Секреты в чат не присылайте.

## 4. Проверить готовность

Откройте [health](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health). Ожидается:

```json
{"ok":true,"version":"0.7.1"}
```

В [конфигурации](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/api/config) проверьте `version: "0.7.1"`, `features.foreignBuyouts: true`, `features.notifications: true`. Если версия старая — не обновилась функция. Если флаги отсутствуют или health сообщает об ошибке — проверьте SQL и Secrets.

Полностью закройте Mini App и снова откройте через бота.

## 5. Как считается покупка

Выставьте точки участка на карте, дождитесь расчёта и подтвердите полную стоимость. Предпросмотр показывает добавляемую площадь, наличие чужой земли и количество затронутых владельцев.

- **Нейтральная земля:** покупатель оплачивает её по 10 🦴/м²; репараций за эту часть нет.
- **Чужая земля:** выкупленная часть переходит покупателю; остаток сохраняется у прежнего владельца. Прежнему владельцу выплачивается **1/10 стоимости его выкупленной части**. Доплаты сверх показанной стоимости нет.
- **Несколько владельцев:** каждый получает выплату только за свою часть. При смешанном контуре стоимость распределяется пропорционально площади нейтральной земли и участков каждого прежнего владельца.
- **Своя земля:** повторно не оплачивается и объединяется с покупкой по правилам v.0.7.

Итоговая цена покупки по-прежнему округляется вверх до целой 🦴. Репарации рассчитываются от реально уплаченной стоимости соответствующей части; дробные косточки сохраняются.

**Пример 1:** Рекс выкупает у Барсика 100 м². Рекс платит 1000 🦴, Барсик получает 100 🦴.

**Пример 2:** из покупаемых 100 м² нейтральные — 70 м², Барсика — 30 м². Цена 1000 🦴, Барсику выплачивается 30 🦴: 10% от стоимости его 30 м².

Выплата, изменение владельцев, сохранение чека и уведомления выполняются одной транзакцией. При нехватке косточек ничего не меняется. Повтор той же покупки после потери ответа не списывает цену и не начисляет репарации повторно.

Доход за время владения фиксируется до изменения границ. Заработанное ранее сохраняется; будущий доход считается по оставшейся площади. Все условия v.0.7 сохраняются: нет лимитов площади/радиуса покупки, есть полный экран карты и подписи k/кк.

## 6. Уведомление владельцу

После успешной покупки бот отправляет прежнему владельцу сообщение:

> Рекс выкупил вашу территорию, вам выплачены репарации в количестве 100 🦴.

Имя — кличка питомца покупателя. В сообщении указана фактически начисленная сумма.

Кнопка **«Уведомления»** в приложении показывает личную историю и количество непрочитанных сообщений. В списке до 50 сообщений, сначала непрочитанные; их можно отметить прочитанными. Другие игроки эту историю не видят.

Telegram отправляется после завершения финансовой операции. При недоступности Telegram или блокировке бота выплата сохраняется, сообщение остаётся в закрытой очереди и в истории приложения. Очередь повторно обрабатывается при покупках и обращениях к уведомлениям; открытое приложение обновляет их каждые 30 секунд. Отдельного постоянно работающего сервера или расписания отправки нет. Обычный повтор запроса не дублирует отправленное сообщение; при потере сетевого подтверждения возможна повторная доставка сообщения, но не повторная выплата.

## 7. Проверка на двух аккаунтах

1. У второго игрока должен быть участок и открытый личный чат бота.
2. Первым игроком выберите часть его территории, проверьте цену и подтвердите покупку.
3. Проверьте новые границы, выплату второму игроку и уведомление в Telegram/приложении.
4. Проверьте смешанную покупку: нейтральная земля не увеличивает репарации продавцу.
5. Отдельно выполните физический GPS-захват: территория переходит по обычным правилам, **репарации и уведомление о выкупе не создаются**.

В браузерном демо выкуп соседа и его кошелёк моделируются локально; настоящий Telegram не вызывается. Проверять реальные сообщения нужно после установки SQL и функции.

## Проверки и публикация

Проверено: 33 теста Edge Function, 13 Node-тестов и 29 проверок настоящей одноразовой PostGIS. Включены частичный/полный выкуп, несколько продавцов, повтор запроса, нехватка средств, доставка/повтор уведомления, приватность истории и отсутствие репараций в обоих режимах GPS. Браузерные сценарии проверяют предпросмотр и историю уведомлений с подменёнными Telegram/API/GPS.

GitHub Pages публикует интерфейс; GitHub Release не устанавливает SQL или Edge Function в Supabase. У среды разработки нет доступа для удалённого применения миграции, поэтому шаги 2–4 выполняет владелец.
