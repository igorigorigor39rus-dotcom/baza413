# DogWars. Захвати мир! — обновление v.0.6

Одна инструкция для работающих v0.2–v.0.5. Профили, фото, территории и начисленные 🦴 сохраняются. Промежуточные версии устанавливать не нужно.

## 1. Скачать новый архив

Скачайте [ZIP v.0.6](https://github.com/igorigorigor39rus-dotcom/baza413/archive/refs/tags/v.0.6.zip), распакуйте в новую папку. Корень проекта — папка, где лежат README.md, scripts и supabase.

## 2. Установить один SQL-файл

Откройте [Supabase](https://supabase.com/dashboard/project/fywsqxijebneqkxusgro) → **SQL Editor → New query**.

Скопируйте **всё содержимое** `supabase/migrations/202611060004_v06.sql` из нового архива, вставьте в редактор, нажмите **Run**. Дождитесь успешного завершения. Пустой результат `pg_advisory_xact_lock` нормален: блокировка освобождается при завершении транзакции.

Для работающего приложения базовую и старые миграции повторно запускать не надо. Для совершенно нового проекта сначала выполните `202611050001_paws.sql`, затем v.0.6. Весь файл выполняется одной транзакцией; при ошибке не запускайте отдельные фрагменты — пришлите текст ошибки без секретов.

## 3. Загрузить Edge Function

В Проводнике откройте корень нового проекта → адресная строка → `cmd` → Enter. Выполните:

```sh
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Если требуется вход: `npx supabase login`, затем повторите команду. На вопрос о загрузке paws-api в ваш проект отвечайте **Yes**. Старый CLI использует `--project-ref` вместо `--remote`.

Существующие секреты `TELEGRAM_BOT_TOKEN`, `APP_URL`, `WEBHOOK_SECRET` остаются прежними.

## 4. Проверить сервер

Откройте [health](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health). Ожидается:

```json
{"ok":true,"version":"0.6.0"}
```

В [конфигурации](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/api/config) проверьте:

- `version: "0.6.0"`;
- `closureMeters: 20`, `maxAccuracy: 20`;
- в `features`: `autoLiveStart`, `crossingRoutes`, `purchases`, `territoryLeaderboard`: true, `purchasePrice: 10`.

Старая версия означает, что не обновилась функция. Отсутствующие флаги или ошибка health — проверьте SQL и Secrets. До обновления серверной части интерфейс сохраняет старый GPS-порог и объясняет недоступность новых функций.

## 5. Обновить webhook

**Нужно повторить и после v.0.5:** новые кнопки «Захватить», «Статус», «Отмена» требуют событий `callback_query`.

В том же окне cmd, в корне нового проекта, выполните команду с **прямыми слешами и кавычками**:

```sh
py -3.12 "./scripts/configure_supabase_bot.py"
```

Для macOS/Linux: `python3.12 ./scripts/configure_supabase_bot.py`.

Введите действующий токен бота, затем **тот же WEBHOOK_SECRET**, который установлен в Supabase Secrets. Символы при вводе не отображаются. Скрипт проверит настройки и включит `message`, `edited_message`, `callback_query`; накопленные сообщения не удаляются. Токен и секрет не записываются на диск и не печатаются. Компьютер после настройки можно выключить.

Если WEBHOOK_SECRET потерян, сохранённое значение обычно нельзя прочитать в Supabase. Создайте новый случайный секрет длиной 32–256 символов из букв, цифр, `_`, `-`, замените его в Edge Functions → Secrets и укажите **это же новое значение** скрипту. Новый токен бота для смены webhook-секрета не нужен. Секреты в чат не присылайте.

## 6. Как теперь гулять

1. Полностью закройте Mini App. В личном чате бота отправьте `/start`. Название приложения — **DogWars. Захвати мир!**, участники — **Генералы**.
2. Если досье ещё нет, откройте «Карта и досье» и создайте его.
3. В чате бота нажмите **скрепку → Геопозиция → Транслировать геопозицию**, выберите, например, 1 час. Предварительно запускать GPS и подготавливать прогулку на карте больше не нужно.
4. Дождитесь **«Прогулка началась»**: первая принятая точка должна иметь заявленную погрешность **≤20 м**. Неточные точки пропускаются; запись начнётся автоматически, когда придёт точная. Её координаты — старт маршрута.
5. Разрешите Telegram точную геопозицию в фоне; при необходимости снимите ограничение энергосбережения. Можно выключить экран. Работа зависит от телефона и частоты обновлений Telegram.
6. Вернитесь **в пределах 20 м от старта**, включите экран и дождитесь свежего обновления координат. Нажмите **«✓ Захватить»** в сообщении бота. Команда `/capture` и захват на карте тоже работают.
7. После успеха остановите трансляцию в Telegram. Кнопка **«Отмена»** удаляет временные точки незавершённой прогулки; трансляцию после неё также остановите самостоятельно.

Кнопка «Гулять с выключенным экраном» на карте отправляет инструкцию в чат и закрывает Mini App. Она больше не запрашивает браузерный GPS и не создаёт пустую прогулку.

Telegram Bot API позволяет кнопкой `request_location` запросить только одну геопозицию. Она не включает Live Location или постоянный фоновый трек. Поэтому вручную включить трансляцию всё равно требуется; обещать автоматическую фоновую запись одним разрешением нельзя. Обычная запись кнопкой «Начать захват» остаётся доступна и требует открытого Mini App.

Последняя точка для захвата должна быть не старше **15 секунд**; этот временной порог не менялся. Погрешность точек ≤20 м, перерыв между принятыми точками ≤45 секунд. Максимум 5000 точек, 2 часа от подготовки, радиус 10 км от старта, площадь 25 м²–10 км². При пропусках или скачках GPS отмените прогулку и начните новую. Продолжение старой трансляции после завершения/отмены не начинает новый захват: для следующей прогулки включите новую трансляцию.

Временные точки фонового маршрута закрыты от прямого доступа. После захвата/отмены удаляются; просроченные прогулки очищаются при обращениях к фоновому API/webhook. Отдельного расписания очистки нет, поэтому без обращений удаление может произойти позднее 2 часов. Контуры территорий остаются общими.

## 7. Пересечения GPS-трека

Самопересечения больше не запрещают захват. Сервер разбивает линии в местах пересечения и объединяет все ограниченные ими площади по внешним границам:

- «Восьмёрка» даёт обе замкнутые петли.
- Повторный проход не удваивает площадь.
- Внутренняя петля не вырезает дыру в участке.
- Незамкнутый отросток не даёт дополнительной площади; вогнутые внешние границы сохраняются.

Вернуться к первой принятой точке в пределах 20 м по-прежнему нужно. Просто пересечь другую часть своего пути недостаточно. Захват чужих территорий прогулкой продолжает работать по общим правилам.

## 8. Покупка свободной земли за 🦴

1. Откройте карту, завершите или отмените текущую прогулку.
2. Нажмите **«Купить свободную территорию · 🦴»**.
3. Ставьте точки нажатием на карту. Нужно 3–100 точек; последняя автоматически соединяется с первой. Точки можно перетаскивать; есть «Убрать точку» и «Очистить».
4. После изменения границ приложение покажет предварительную площадь, затем запросит у сервера точную площадь WGS84, свободность и стоимость.
5. Цена — **1 м² = 10 🦴**. Итог округляется вверх до целой 🦴. Например, 100 м² стоят 1000 🦴. Покупаемая площадь — от 25 м² до 10 км², все точки в радиусе 10 км от первой.
6. Нажмите «Купить за … 🦴» и подтвердите сумму. При нехватке баланса покупка недоступна.

Покупать можно **только полностью свободную площадь**, включая отсутствие пересечения с собственными участками. Общая граница с занятым участком допускается. Если участок заняли после расчёта, покупка отклоняется без списания. Для покупки рисуйте границу без самопересечений; разрешение пересечений GPS-трека относится к прогулкам.

Списание и добавление территории выполняются одной транзакцией. При сетевом сбое можно повторить ту же покупку: номер запроса сохраняется, повтор не списывает деньги ещё раз. Изменение точек создаёт новую покупку, поэтому после неопределённого ответа сначала повторите прежний запрос или проверьте карту/баланс.

Купленный участок закрашивается стилем владельца и приносит обычный доход **1 м² = 1 🦴 в час**. Он может быть перезахвачен прогулкой другим Генералом. Покупка не даёт защиты от захвата.

## 9. Фото и два рейтинга

В **«ТОП-10 Генералов»** переключаются вкладки **«По 🦴»** и **«По территории»**. Вторая учитывает текущую площадь всех оставшихся участков, включая купленные. Потерянная площадь убирается из рейтинга. При равенстве показателя порядок определяется ID.

Рядом с именем отображается фото. Нажатие фото открывает его крупно, имя открывает досье. Фото в досье тоже можно увеличить. Просмотр использует уже сохранённое изображение: фотографии по-прежнему сжимаются до 1 МБ.

## Публикация и проверки

GitHub Release содержит исходники; GitHub Pages публикует интерфейс из `prototype /docs`. Они не обновляют Supabase и webhook. У среды разработки нет доступа для применения изменений в вашем Supabase, поэтому шаги 2–5 выполняет владелец.

Проверено: 29 тестов Edge Function, 23 Python-теста, 8 Node-тестов; 18 проверок настоящей одноразовой PostGIS, включая конкурирующие покупки и геометрию пересечений. Браузерные сценарии используют подменённые Telegram SDK/API/GPS: реальную запись телефона проверьте короткой прогулкой после установки.

Демо: https://igorigorigor39rus-dotcom.github.io/baza413/?demo=1 — локальные данные этого браузера. Для теста покупки сначала захватите демоучасток и накопите 🦴; деньги рабочей базы не используются. Фоновый режим требует настоящего Telegram webhook и в демо отключён.
