# Исправление завершения прогулки · v.1.1.3

[Скачайте архив v.1.1.3](https://github.com/igorigorigor39rus-dotcom/baza413/releases/download/v.1.1.3/baza413-v.1.1.3.zip) и распакуйте в новую папку. Откройте папку `baza413-v.1.1.3`, где находятся `README.md`, `supabase` и `scripts`. Старый архив v.1.1.2 этого исправления не содержит.

Бот раньше отклонял завершение, если последняя принятая точка была старше 15 секунд. Telegram обновляет трансляцию нерегулярно: уже записанный замкнутый маршрут из-за этого мог не завершиться. Теперь такой маршрут можно завершить между обновлениями. Служебное подтверждение кнопки и учёт активности не задерживают захват; запрос к базе ограничен 15 секундами. При сбое бот предлагает проверить статус и повторить действие. Повтор не создаёт вторую территорию и не списывает косточки.

Инструкция для работающей **v.1.1.2**. Балансы, анкеты, территории и токены сохраняются. Старые миграции повторять не нужно. Для более ранней версии сначала установите [v.1.1.2](UPDATE_V1_1_2.md).

## 1. Загрузить функцию

Откройте терминал в папке новых файлов, где находятся `README.md`, `supabase` и `scripts`. Выполните:

```powershell
npx supabase login
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Если появится вопрос `Deploy 1 Function ...?`, ответьте **Yes**. Дождитесь сообщения об успешной загрузке.

## 2. Выполнить один SQL-файл

1. Откройте Supabase → проект **fywsqxijebneqkxusgro** → **SQL Editor** → **New query**.
2. Откройте файл `supabase/migrations/202611120001_live_completion.sql` в новых файлах проекта.
3. Скопируйте **весь** его текст, вставьте в SQL Editor и нажмите **Run**.
4. Дождитесь успешного выполнения. Отсутствие строк в результате нормально.

Не заменяйте этот файл старой накопительной миграцией `202611080002_v111.sql`: она вернёт прежнюю проверку свежести GPS.

## Проверка

Откройте:

https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health

Ожидаемый ответ:

```json
{"ok":true,"version":"1.1.3"}
```

В `/api/config` должен появиться флаг `features.storedLiveCompletion: true`. Если `/health` просит `202611120001_live_completion.sql`, выполните шаг 2; если версия осталась `1.1.2`, повторите шаг 1 из папки новых файлов.

Дождитесь завершения публикации GitHub Pages, полностью закройте Mini App и откройте снова. Обновлённый интерфейс перестанет требовать «свежую точку» у сохранённого трека. Загрузка Edge Function сама сайт не обновляет.

Включите новую трансляцию в чате **@DoggyW_bot**, пройдите небольшой замкнутый маршрут и нажмите **«Захватить»**. Проверьте результат кнопкой **«Статус»** или на карте. Если ответ потерялся, повторите **«Захватить»**: сервер вернёт результат уже завершённой прогулки.

Для успешного завершения точка возвращения должна **поступить в бот** и быть в пределах 20 м от первой точки. Если телефон не передал её, бот не может достроить маршрут: откройте трансляцию в Telegram, проверьте её обновление и разрешения точной геопозиции в фоне, дождитесь точки и повторите захват. Трансляцию останавливайте после подтверждения захвата.

Сохраняются точность до 20 м, замыкание до 20 м, контроль средней скорости 20 км/ч, ограничения прогулки по времени и размеру, а также один записывающий аккаунт на питомца. Чужой привязанный аккаунт завершить эту прогулку не может. Функция бота обратной связи `dogwars-feedback` не меняется. `WEBHOOK_SECRET`, токен и `configure_supabase_bot.py` трогать не нужно.

## Проверки исправления

На локальной PostGIS воспроизведён прежний отказ на замкнутом треке с последней точкой 90 секунд назад. После исправления проходят 24 проверки маршрутов и доступа, включая финиш с точкой 90/240 секунд назад, открытый контур, точность, скорость, пересечения, общий аккаунт и одновременные повторы захвата. Пройдены 68 тестов API, 10 тестов синхронизации и браузерный smoke с проверкой доступности кнопки на новой схеме и совместимости со старой. Рабочая база и настоящий Telegram в этих проверках не использовались.
