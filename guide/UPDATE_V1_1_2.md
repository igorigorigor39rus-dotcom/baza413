# Обновление DogWars до v.1.1.2

Оптимизированы фоновые запросы и передача маршрута/чата. Активный маршрут и открытый чат по-прежнему обновляются раз в 10 секунд. При обычном просмотре выполняется один общий запрос в минуту. После действий пользователя, возврата из фона и восстановления сети данные обновляются сразу. Старые ответы не возвращают потраченные косточки и не смешивают каналы чата.

Инструкция рассчитана на работающую v.1.1.1. Если установлена более старая версия, сначала обновите её по [инструкции v.1.1.1](UPDATE_V1_1_1.md). Для новой установки нужны базовая миграция `202611050001_paws.sql`, затем `202611080002_v111.sql`, затем новое обновление ниже.

## 1. Скачать и распаковать

[Скачать архив v.1.1.2](https://github.com/igorigorigor39rus-dotcom/baza413/releases/download/v.1.1.2/baza413-v.1.1.2.zip).

Распакуйте в новую папку. Откройте терминал в папке **`baza413-v.1.1.2`**, где находятся `README.md`, `scripts` и `supabase`. Если ZIP создал дополнительную внешнюю папку, зайдите внутрь до этих файлов.

## 2. Сначала загрузить функцию

Выполните по очереди:

```powershell
npx supabase login
```

```powershell
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Подтвердите **Yes** именно для **paws-api**. Если CLI не распознаёт `--remote`, используйте `npx supabase@latest` вместо `npx supabase`.

Порядок важен: сначала появляется обработчик нового запроса, затем SQL включает его использование. До выполнения SQL сайт остаётся совместим с прежним режимом. Проверку `/health` делайте после следующего шага: до установки SQL она может сообщать о недостающей миграции.

## 3. Выполнить один новый SQL-файл

Откройте [Supabase → SQL Editor](https://supabase.com/dashboard/project/fywsqxijebneqkxusgro/sql/new) в **том же проекте, где работает игра**.

1. Нажмите **New query**.
2. В распакованном архиве откройте `supabase/migrations/202611100001_efficient_sync.sql`.
3. Скопируйте **всё содержимое** файла в SQL Editor.
4. Нажмите **Run** и дождитесь успешного завершения.

Для работающей v.1.1.1 старые SQL-файлы повторно выполнять не нужно. Новая миграция не удаляет анкеты, территории, косточки, штаб или историю платежей. Повторное выполнение этого нового файла сохраняет данные.

## 4. Проверить и открыть приложение заново

Откройте:

https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health

Ожидаемый ответ:

```json
{"ok":true,"version":"1.1.2"}
```

На странице [настроек API](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/api/config) должны быть `version: "1.1.2"` и `features.efficientSync: true`.

Полностью закройте Mini App и откройте его снова через игрового бота. Сайт GitHub Pages обновляется автоматически; вручную загружать `docs` не требуется.

Проверьте отправку сообщения в чат, открытие уведомлений и штаба, отображение баланса. На прогулке новые точки отображаются раз в 10 секунд; сама запись по-прежнему идёт через трансляцию геопозиции Telegram. Возврат из фона должен сразу обновлять данные.

Токен игрового бота, `WEBHOOK_SECRET`, расписание и остальные секреты остаются прежними. Команду `configure_supabase_bot.py` повторять не нужно. Отдельный бот обратной связи и функция `dogwars-feedback` этим обновлением не меняются.

## Если проверка не проходит

- **NOT_FOUND / Requested function was not found:** проверьте успешное завершение deploy **paws-api** и выбранный проект.
- **Версия 1.1.1:** функция ещё не обновлена; выполните deploy из папки нового архива.
- **Сообщение об отсутствующей миграции:** выполните весь новый SQL из шага 3. Для старых версий сначала требуется обновление v.1.1.1.
- **efficientSync отсутствует или false:** SQL не установлен либо после него повторно выполнялась старая миграция; повторите новый SQL v.1.1.2.
- **Старый интерфейс:** полностью закройте Mini App и откройте снова после завершения публикации GitHub Pages.

## Изменения и проверки

Добавлены единый цикл обновления, GPS/чат-дельты, защита устаревших ответов, восстановление курсора и повторы после сетевых ошибок. Минутная точность активности сохранена. Финансовые операции и правила захвата прежние.

Пройдены 63 теста API, 10 тестов цикла и 12 сценариев Chromium с настоящей локальной PostGIS/API, а также прежний браузерный smoke. [Условия и результаты сравнительных испытаний](OPTIMIZATION_V1_1_2.md). Локальная нагрузка не является гарантией вместимости Supabase Free.
