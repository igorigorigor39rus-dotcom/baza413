# Обновление DogWars до v.0.8

Одна инструкция для уже работающего бота v0.2–v.0.7.1. Существующие досье, участки и балансы сохраняются. VPS и постоянно включённый компьютер не нужны. Публикация GitHub обновляет интерфейс; серверные шаги Supabase выполняет владелец проекта.

## 1. Скачать релиз

Скачайте [ZIP v.0.8](https://github.com/igorigorigor39rus-dotcom/baza413/archive/refs/tags/v.0.8.zip) и распакуйте в новую папку. Далее команды выполняются в папке, где лежат `README.md`, `scripts` и `supabase`.

## 2. Обновить базу

В [Supabase SQL Editor](https://supabase.com/dashboard/project/fywsqxijebneqkxusgro/sql/new) создайте **New query**, вставьте **весь** файл [202611060007_v08.sql](../supabase/migrations/202611060007_v08.sql), нажмите **Run** и дождитесь успешного выполнения.

Для первой установки сначала выполните базовый `202611050001_paws.sql`, затем этот v08. Промежуточные миграции запускать не требуется. `pg_advisory_xact_lock` в результате — нормальная транзакционная блокировка для согласованного изменения территорий и кошельков.

## 3. Развернуть Edge Function

В PowerShell из распакованной папки:

```powershell
npx supabase login
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

На вопрос о развёртывании `paws-api` ответьте **Yes**. Секреты `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET` и `APP_URL` остаются прежними. Вход пользователей проверяет сама функция по подписи Telegram; отдельный Supabase JWT здесь не используется.

Проверка: откройте https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health — ожидается `{"ok":true,"version":"0.8.0"}`. Ошибка 503 с просьбой установить миграцию означает, что шаг 2 не выполнен полностью; `NOT_FOUND` означает, что функция не развёрнута в этом проекте.

## 4. Обновить webhook — обязательно для оплаты Stars

В PowerShell выполните:

```powershell
py -3.12 .\scripts\configure_supabase_bot.py
```

Если уже находитесь внутри папки `scripts`, используйте `py -3.12 .\configure_supabase_bot.py`. Не склеивайте `scripts` и имя файла без обратной косой черты.

Введите действующий токен бота и сохранённый `WEBHOOK_SECRET`; ввод скрыт. Скрипт добавит `pre_checkout_query` к разрешённым обновлениям Telegram, сохранит обновления геопозиции и настроит команды `/shop`, `/paysupport`, `/reminders_on`, `/reminders_off`. Без этого шага Telegram может не передавать запрос на подтверждение покупки.

## 5. Включить расписание напоминаний

1. В SQL Editor создайте ещё один **New query**.
2. Вставьте целиком [supabase/setup_reminders.sql](../supabase/setup_reminders.sql) и нажмите **Run**. Этот файл предназначен именно для Supabase: включает Cron, pg_net и Vault.
3. Последний результат содержит `scheduler_secret_for_edge_functions`. Скопируйте значение.
4. Откройте **Edge Functions → Secrets → Add secret**. Имя: **`SCHEDULER_SECRET`**, значение — скопированная строка. Сохраните. Это отдельный секрет, не `WEBHOOK_SECRET`.
5. Откройте https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/api/config — ожидаются `version: "0.8.0"`, `features.reminders: true`, `features.starShop: true`, `features.largestTerritory: true` и `schedulerConfigured: true`.
6. В Supabase **Integrations → Cron** или в SQL проверьте задание `dogwars-reminders-v08`. Оно запускается раз в минуту; функция выбирает только подходящих получателей. Повторный запуск setup SQL обновляет то же задание.

Секрет хранится в Vault, а в расписании стоит обращение к Vault. Для повторного просмотра владельцем:

```sql
select decrypted_secret from vault.decrypted_secrets
where name = 'dogwars_scheduler_secret';
```

Не публикуйте результат в GitHub или чате. Если ваш проект Supabase приостановлен, расписание и бот не работают до возобновления проекта.

## Что изменилось и как проверить

### Ограничение скорости

В обычной прогулке и трансляции Telegram сервер делит сумму длин всех последовательных принятых GPS-отрезков на время между первой и последней GPS-точкой. При средней скорости **выше 20 км/ч** захват окончательно аннулируется:

> Ай яй яй, захват аннулирован, играй честно

Ровно 20 км/ч допускается. Повторные круги входят в расстояние, искусственное замыкание контура — нет. Данные о недопустимой точности, скачках и пропусках GPS проверяются отдельно, прежде чем считать скорость. После аннулирования нельзя повторно отправить укороченный или более медленный вариант той же прогулки; нужно начать новую. Территории и кошельки при отказе не меняются.

Средняя скорость — базовая защита: долгое ожидание может понизить среднюю скорость поездки, а подмену GPS такой расчёт сам по себе не обнаруживает. Ограничения качества GPS продолжают действовать. Демо-маршрут не выдаётся за физическую прогулку. Замыкание контура и точность GPS остаются до **20 м**. При физическом захвате **репарации не выплачиваются**.

### Напоминания в 08:00 и 18:00

Откройте Mini App после обновления: часовой пояс устройства, например `Europe/Kaliningrad`, сохранится без запроса GPS. После поездки он обновится при следующем посещении. Пользователям без известного часового пояса сообщения не отправляются.

Если пользователь не посещал приложение и не взаимодействовал с ботом **больше 48 часов**, бот напоминает о прогулке в **08:00 и 18:00 по его сохранённому местному времени**. Активное приложение обновляет время посещения. Системные платежные события и автоматические обновления live-location не считаются посещением. Напоминания работают до нового посещения или отключения.

Настройка находится в своём досье. Также работают `/reminders_off` и `/reminders_on`; в напоминании есть кнопка отключения. Повтор cron не создаёт повторное напоминание за ту же дату и время. При сбоях отправка повторяется в течение первых 15 минут соответствующего часа; старые напоминания не рассылаются позже. Точное время доставки зависит от Supabase и Telegram. При потере подтверждения доставки возможен повтор сообщения, но не финансовой операции.

### Покупка косточек за Telegram Stars

В Mini App нажмите **«Купить 🦴»**, либо отправьте **`/shop`** в личный чат бота. Сначала создайте досье питомца.

| Цена | Начисление |
| --- | --- |
| 100 ⭐ | 10 000 🦴 |
| 250 ⭐ | 30 000 🦴 |
| 500 ⭐ | 80 000 🦴 |
| 1000 ⭐ | 200 000 🦴 |

Счёт выставляется в **XTR (Telegram Stars)**. Отдельный платёжный провайдер и VPS не нужны. Стоимость приобретения Stars в рублях показывает Telegram; фиксированного курса в рублях приложение не устанавливает.

Сервер фиксирует цену в заказе, подтверждает допустимость оплаты и начисляет косточки только по `successful_payment` из защищённого webhook. Создание счёта, закрытие окна оплаты или сообщение браузера об успехе не начисляют валюту. Срок начала оплаты по счёту — 20 минут; для просроченного создайте новый. Повторная доставка одного платежа не дублирует баланс. Баланс и покупки земли продолжают хранить полные числа, сокращения k/кк касаются только отображения.

В браузерном демо видны пакеты, но настоящая оплата отключена. Для приёмки реальной оплаты после серверных шагов используйте Telegram и минимальный пакет, учитывая списание настоящих Stars. При отмене оплаты начисления нет.

**Поддержка:** `/paysupport описание вопроса` сохраняет обращение владельцу. Оператор смотрит закрытые таблицы `paws.payment_support` и `paws.payment_issues` через SQL Editor/Table Editor. Автоматической рассылки обращений другим людям нет. Журнал заказов и платежей: `paws.star_orders`, `paws.star_payments`.

При корректном Telegram-событии возврата купленные косточки отзываются. Если часть уже потрачена, недостающая сумма погашается последующими доходами и пополнениями; баланс не становится отрицательным. Если платёж не сопоставляется со счётом, сервер сохраняет проблему и запрашивает возврат Stars; неуспешные возвраты требуют проверки оператором. Ручной возврат владелец проводит через Telegram `refundStarPayment`, затем проверяет событие в журнале. Не редактируйте оплаченные заказы и не удаляйте финансовые таблицы.

### «Показать территорию» в досье

Кнопка есть в своём досье и карточке другого игрока. Она получает с сервера самый большой участок по площади, закрывает карточку, разворачивает карту и помещает участок целиком в окно. Участок подсвечивается даже за пределами прежнего окна карты. Если земли нет, карточка остаётся открытой с пояснением. В ТОП-10 откройте досье по имени генерала; фото по-прежнему увеличивается отдельно.

## Проверки разработки

Пройдено 43 проверки Edge Function/API, 43 проверки PostGIS, Node-проверки, установка базы с нуля и браузерные сценарии. Проверки выполняются на одноразовой PostGIS, локальном браузере с подменёнными GPS/Telegram/API и моках Telegram Bot API. Проверены порог скорости в двух режимах, неизменность земли и кошельков при аннулировании, повторные платежи, возвраты и остаток долга, часовые пояса/DST, отключение и возвращение пользователя, крупнейший участок и сохранение прежних покупок с репарациями. Реальные платежи, отправки ботом и расписание в рабочем Supabase требуют шагов владельца выше.
