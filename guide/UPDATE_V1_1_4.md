# Обновление DogWars до v.1.1.4

Снят лимит длительности прогулки. Остановка или истечение срока трансляции больше не мешает захватить уже записанный замкнутый трек. Ошибки базы показывают код, по которому можно найти причину сбоя. Точность, замыкание, контроль скорости, ограничения геометрии и один записывающий аккаунт сохраняются.

Инструкция для установленной v.1.1.3. [Скачайте архив v.1.1.4](https://github.com/igorigorigor39rus-dotcom/baza413/releases/download/v.1.1.4/baza413-v.1.1.4.zip), распакуйте в новую папку и откройте папку `baza413-v.1.1.4`, где находятся `supabase`, `scripts` и `README.md`.

Если есть незахваченный маршрут, **сначала выполните SQL ниже**. До этого не запускайте новую трансляцию и не нажимайте «Отмена»: эти действия заменяют/удаляют прежний трек. Миграция сохраняет существующие активные маршруты. Точки, уже удалённые старой версией, автоматически восстановить невозможно.

## 1. Выполнить один SQL

1. Supabase → проект **fywsqxijebneqkxusgro** → **SQL Editor → New query**.
2. Откройте в новых файлах `supabase/migrations/202611130001_unlimited_walks.sql`.
3. Скопируйте **весь** файл, вставьте в SQL Editor и нажмите **Run**.
4. Дождитесь успешного выполнения. Отсутствие строк результата нормально.

Старые миграции повторять не нужно: они вернут прежние ограничения. Этот SQL заменяет функции и добавляет флаги возможностей; балансы, анкеты и активные маршруты не сбрасываются.

## 2. Загрузить функцию

Откройте PowerShell в папке нового архива. Если нужна авторизация:

```powershell
npx supabase login
```

Затем:

```powershell
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

На вопрос о загрузке ответьте **Yes** и дождитесь успешного завершения. В архиве есть все модули функции, включая новый `rpc-errors.ts`.

## 3. Проверить

Откройте https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health — ожидается:

```json
{"ok":true,"version":"1.1.4"}
```

В `/api/config` должны быть `features.unlimitedWalkDuration: true` и `features.recordedFinishAfterStop: true`.

Если `/health` просит `202611130001_unlimited_walks.sql`, выполните шаг 1. Если версия `1.1.3`, повторите загрузку из новой папки. GitHub Pages обновляется отдельно при публикации репозитория; полностью закройте Mini App и откройте снова.

Если прежний трек ещё сохранён и активен, нажмите **«Захватить»** в боте. Он должен быть замкнут по записанным точкам в пределах 20 м и пройти остальные проверки. Начинать новый маршрут для этого не требуется. Остановка трансляции сама по себе захват не выполняет — нужна кнопка бота.

Токен бота, `WEBHOOK_SECRET`, расписание и бот обратной связи остаются прежними. `configure_supabase_bot.py` повторно не запускается.

## Если захват снова выдаёт ошибку базы

Пришлите полный текст ответа бота с кодом. Код `P0001` обозначает игровой отказ; коды `57014`, `55P03`, `40P01`, `PGRST003` — ожидание/занятость базы; `PGRST202` — отсутствующую функцию или её описание в кеше API. Точный код важнее общей надписи о недоступной базе.

Можно выполнить весь файл `guide/CAPTURE_DIAGNOSTICS.sql` в SQL Editor. Он делает пробный захват в откатываемом блоке и возвращает `capture_diagnostics`: код, сообщение, место ошибки, права RPC и состояние трансляции. Территории, маршрут и баланс после проверки сохраняются. Скрипт помогает найти причину, но не является миграцией.
