# Обновление DogWars до v.1.1.1

Добавлены удаление анкеты, более чёткие фоны штаба и заметная анимация питомца. Сайт публикуется через GitHub Pages автоматически. Для работающего бота достаточно одного SQL-файла и загрузки Edge Function.

## 1. Скачать файлы

[Скачать архив обновления v.1.1.1](https://github.com/igorigorigor39rus-dotcom/baza413/releases/download/v.1.1.1/baza413-v.1.1.1.zip), распаковать в новую папку. Команды выполняются в папке `baza413-v.1.1.1`, где лежат `README.md` и `supabase`.

## 2. Выполнить SQL

В [Supabase → SQL Editor](https://supabase.com/dashboard/project/fywsqxijebneqkxusgro/sql/new) → **New query** вставьте **весь** файл [202611080002_v111.sql](../supabase/migrations/202611080002_v111.sql) → **Run**.

Это одно накопительное обновление для работающих версий до v.1.1 включительно. Промежуточные миграции не нужны. Для новой установки сначала выполните базовый `202611050001_paws.sql`, затем v111. Старые миграции после v111 не запускайте. `pg_advisory_xact_lock` — нормальная блокировка.

SQL сам не удаляет анкеты: он добавляет кнопку и серверную возможность удаления. Существующие анкеты, баланс, территории, общий доступ и уровень штаба сохраняются. Повтор SQL их не обнуляет.

## 3. Загрузить функцию

```powershell
npx supabase login
npx supabase functions deploy paws-api --remote=fywsqxijebneqkxusgro --no-verify-jwt
```

Подтвердите **Yes**. [Проверка готовности](https://fywsqxijebneqkxusgro.supabase.co/functions/v1/paws-api/health) должна вернуть `{"ok":true,"version":"1.1.1"}`. В `/api/config` должны быть `features.deletePet: true` и `features.highQualityHQ: true`.

Токен, секреты, webhook, расписание и настройки GitHub Pages остаются прежними. Папку `docs` вручную загружать не нужно. Полностью закройте Mini App и откройте через бота снова.

## 4. Как удалить анкету и привязать аккаунт

1. Войдите именно в аккаунт, чью собственную анкету нужно удалить.
2. Откройте **Профиль → Удалить анкету питомца**.
3. Прочитайте список удаляемых данных, введите точную кличку и подтвердите, что понимаете необратимость.
4. Нажмите **«Удалить навсегда»**. Удалятся анкета, территории, кошелёк, штаб, сообщения питомца и незавершённая прогулка; второй аккаунт будет отвязан. Фото удаляется через очередь Storage, с повтором при сетевом сбое.
5. После перезагрузки приложение сообщит, что аккаунт свободен. **Не создавайте новую анкету.** Откройте ссылку-приглашение от основного аккаунта и подтвердите привязку в боте.

Второй аккаунт не может удалить общую анкету основного. Удаление не объединяет землю и косточки двух питомцев и не возвращает Stars автоматически. История платежей сохраняется отдельно; поздний платёж для удалённой анкеты направляется на возврат плательщику. Уже учтённый платёж не возвращается автоматически из-за удаления; поздний возврат не списывает косточки у новой анкеты или другого питомца.

Если есть непогашенный остаток по возвратам Stars, сначала нужно погасить его. Старый запрос удаления после сетевого сбоя безопасно повторяется и не удаляет новую или привязанную общую анкету. Запоздавшее сохранение старой анкеты также отклоняется.

## 5. Качество штаба и движение

Каждый из десяти уровней теперь использует отдельный фон **1672×941**, примерно в 3,2 раза шире прежнего фрагмента атласа. Загружается только текущий уровень, изображения сжаты в WebP. Стилистику комнат и развитие от бедного убежища до генеральского штаба сохранили.

Анимация автоматически запускается при каждом открытии штаба: питомец дышит и покачивается. Нажмите на него — он подпрыгнет. Кнопки включения движения нет; старое сохранённое выключение не мешает новому автоматическому запуску. При системном уменьшении движения остаётся плавное дыхание без раскачивания и подскоков.

Рисунки 120 пород и цены улучшений не изменены. Прочие правила, второй аккаунт и GPS описаны в [инструкции v.1.1](UPDATE_V1_1.md).

## Как устроено в коде

`web/pet-deletion.mjs` показывает подтверждение и повторяет одну операцию при потере ответа. `profileId` различает старую и новую анкету одного Telegram-пользователя. SQL одной транзакцией проверяет владельца, освобождает землю, убирает игровые данные и сохраняет платёжные записи. Очередь `paws.photo_cleanup` удаляет фото через Edge Function; повторы идут при последующих открытиях приложения и запуске уже настроенного планировщика.

`web/headquarters.mjs` выбирает отдельный фон и управляет движением. Исходные PNG лежат в `design/hq-v111`, WebP для приложения — в `web/assets/hq/level-*.webp`. Компактный архив содержит все рабочие файлы; оригиналы PNG доступны в полном Source code ZIP на странице релиза.
