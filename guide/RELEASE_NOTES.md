DogWars v.1.1.1: удаление анкеты, чёткие комнаты штаба и заметное движение питомца.

- Профиль → «Удалить анкету питомца»: только основной аккаунт, подтверждение точной кличкой, явное предупреждение потери игровых данных.
- После удаления аккаунт можно привязать к другому питомцу; кошелёк, земля и штаб не переносятся.
- История Stars сохраняется. Поздние платежи, возвраты и повторы старых запросов не затрагивают новую или общую анкету.
- Десять отдельных фонов 1672×941 вместо миниатюр атласа; прежняя стилистика и уровни.
- Автоматическое дыхание и покачивание без кнопки включения; подскок по нажатию. При уменьшении движения — спокойное дыхание.

**Обновление:** скачайте приложенный ZIP, выполните `supabase/migrations/202611080002_v111.sql`, затем загрузите `paws-api`. [Пошаговая инструкция](https://github.com/igorigorigor39rus-dotcom/baza413/blob/v.1.1.1/guide/UPDATE_V1_1_1.md). Webhook и секреты не меняются. Публикация GitHub сама не применяет SQL в Supabase.

SQL миграции не удаляет анкеты автоматически. Удаление выполняется только после подтверждения владельца в приложении. При наличии непогашенного остатка по возвратам Stars сначала требуется погашение.

Проверки используют локальную PostGIS и подменённые Telegram/API/GPS. Рабочие данные пользователей не удалялись; реальные платежи не выполнялись.
